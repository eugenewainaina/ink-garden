# Reference source

`nonflowers-main.js` is the complete engine from
[LingDong-/nonflowers](https://github.com/LingDong-/nonflowers), **MIT licensed**,
vendored here as a reading reference for M0c.

It is not used at runtime and must not be. If any of it is ever ported rather
than reimplemented, the MIT notice and attribution travel with it.

See `../2026-10-03-nonflowers-techniques.md` for what to take from it and what
deliberately not to.
